# High-Density Operations Frontend Design Guidelines

- **Theme & Palette:** Dark operations aesthetic (`#09090B` dark background, `#18181B` card containers, sharp borders `#27272A`).
- **Accent Status Colors:**
  - Critical/Low: `#EF4444` (Red) / `#F97316` (Amber)
  - Healthy/Complete: `#10B981` (Emerald)
  - Processing: `#3B82F6` (Blue)
- **Typography:** High legibility, monospaced tabular numbers for counts/SKUs, clean sans-serif for UI labels.
- **Micro-interactions:** Smooth state transitions, subtle borders, SVG overlay tracking for bounding boxes.
- **Component Polish:** Never use generic white backgrounds or soft drop shadows. Use crisp dark borders and dense grid alignments.
